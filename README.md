# Cyber Threat Research Assistant

Cyber Threat Research Assistant is an AI-powered research application designed to help users explore and understand academic research on cybersecurity threats, particularly phishing and malicious content. It uses hybrid retrieval (BM25 and dense vector search), Reciprocal Rank Fusion (RRF), and Cross-Encoder reranking to retrieve relevant research passages. Google's Gemini API then generates evidence-based answers grounded in the retrieved academic papers, with citations and references to support research and analysis.
